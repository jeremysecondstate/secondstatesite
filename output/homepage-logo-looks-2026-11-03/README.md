# SECONDSTATE homepage logo looks

Created 3 November 2026 with the built-in image generation tool.

These are desktop homepage design mockups. No application source or deployed website was changed.

## Looks

1. **Warm editorial** — ivory hero with an oversized pale-gold printing-plate emblem, editorial serif typography, and a clear gallery action.
2. **Evening monogram** — charcoal hero with a large subdued-gold SS monogram and warm ivory foreground text.
3. **Graphic gallery** — an oversized stacked SECOND / STATE wordmark as a pale typographic background, with a bold contemporary navigation style.

All three use the supplied logo concepts and the site's existing historic printmaking image as visual references. The main heading and actions follow the current homepage. The supporting line is taken from the existing public Gallery page.
